===== API INFORMATION =====
API Base URL: https://story-api.dicoding.dev/v1
API Documentation: https://story-api.dicoding.dev/v1

API Key Required: No
Authentication: Token-based (Bearer Token in Authorization header)
Endpoints Used:
- POST /register - User registration
- POST /login - User login
- GET /stories - Get all stories (paginated)
- POST /stories - Add new story (multipart form data)

===== MAP SERVICE INFORMATION =====
Map Library: Leaflet.js (https://leafletjs.com/)
Tile Providers:
1. OpenStreetMap (Default)
   - URL: https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
   - Attribution: © OpenStreetMap contributors
   - API Key Required: No

2. Satellite/Imagery (Esri World Imagery)
   - URL: https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}
   - Attribution: Tiles © Esri
   - API Key Required: No

===== RESPONSIVE BREAKPOINTS =====
Mobile:        375px (small phones)
Tablet:        768px (tablets)
Desktop:      1024px (laptops and above)
Extra Large:  1200px (large monitors)

Layout adjustments by breakpoint:
- Navigation drawer: Fixed mobile, inline desktop
- Stories sidebar: Stack on mobile, side-by-side on desktop
- Forms: Full width on mobile, centered with max-width on desktop
- Map height: 300px→450px→500px→600px as viewport grows

===== AUTHENTICATION =====
Registration & Login Flow:
1. User can register with name, email, password
2. Server returns token and user info
3. Token stored in localStorage
4. Authenticated users can see home page and add stories
5. Logout available in navigation menu
